# Ejemplo: in-coming

Documentos del primer proyecto real convertido con unity2ue, el juego **in-coming** (Unity) →
`InComingUE` (Unreal 5.8). Son específicos de ese juego y sirven como ejemplo de uso de los comandos
`personajes`, `arma`, `retratos` y `sonido` y de los retoques por proyecto (`Content/Python/unity2ue_import/extra/`).

- [03-personajes-y-armas.md](03-personajes-y-armas.md): cómo cambiar el jugador, su arma, los enemigos y el jefe.
- [04-cambios-del-28-09.md](04-cambios-del-28-09.md): resumen de los cambios de juego añadidos sobre la conversión.

La documentación general del conversor está en [`docs/01`](../../01-lo-aprendido-unity-a-unreal.md) y [`docs/02`](../../02-como-convertir-proyectos-unity-a-unreal.md).
